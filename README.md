# clanker

## Projects

- [airdrop](airdrop/) — macOS command-line tool for sharing local files and web
  URLs with Apple devices through AirDrop. Install with Homebrew or build with
  Apple's Command Line Tools.
- [qr](qr/) — tiny dependency-free C tool that renders QR codes as bitmaps
  directly in the terminal (iTerm2 inline images and the kitty graphics
  protocol; works on macOS, Linux and Windows Terminal). Build with CMake.

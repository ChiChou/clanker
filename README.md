## Projects

### [airdrop](airdrop/)
  
Invoke airdrop from command line

```sh
brew install chichou/tap/airdrop
```

### [qr](qr/)

tiny dependency-free C tool that renders QR codes as bitmaps

directly in the terminal (iTerm2 inline images and the kitty graphics
protocol; works on macOS, Linux and Windows Terminal). Install with Homebrew
or build with CMake.

```sh
brew install chichou/tap/qr
```
